# 接线说明

## 1. 目标

本项目使用两台 Arduino Uno 组成一个对称的单线半双工莫尔斯电报系统。

两块板子烧录同一份程序，默认引脚定义如下：

- `D2`：单线通信
- `D13`：发送提示蜂鸣器
- `D12`：接收提示绿色 LED

---

## 2. 器件清单

- Arduino Uno x 2
- 绿色 LED x 2
- LED 限流电阻 x 2
  - 建议 `220Ω` 到 `1kΩ`
- 9013 NPN 三极管 x 2
- 基极电阻 x 2
  - 建议 `1kΩ`
- 二极管 x 2
  - 建议 `1N4148` 或 `1N4007`
- 蜂鸣器 x 2
- 杜邦线若干

可选但推荐：

- 总线上拉电阻 x 1
  - 建议 `4.7kΩ` 到 `10kΩ`

---

## 3. 总体连接原则

这个项目虽然叫“单线通信”，但硬件上不是只接一根线。

至少需要两根线连接两块板子：

1. `D2 <-> D2` 数据线
2. `GND <-> GND` 共地线

注意：

- **不共地就不能稳定通信**
- 程序逻辑是“拉低为有效，释放为高电平空闲”
- 为了更稳，建议在总线上加一个外部上拉电阻到 `5V`

---

## 4. 两块板子之间怎么接

### 4.1 数据线

- Arduino A `D2` 连接 Arduino B `D2`

### 4.2 共地

- Arduino A `GND` 连接 Arduino B `GND`

### 4.3 可选上拉

推荐在总线节点上加一个上拉电阻：

- `D2` 总线节点通过 `4.7kΩ` 或 `10kΩ` 上拉到 `5V`

说明：

- 代码里已经使用 `INPUT_PULLUP`
- 但外部上拉会让单线总线更稳定

---

## 5. 每块板子的本地接线

两块板子的本地接法完全一样。  
下面以“单块 Arduino Uno”为例说明。

---

## 6. 绿色 LED 接法

功能：

- 本机接收消息时点亮

连接方法：

1. `D12` 接到限流电阻一端
2. 限流电阻另一端接 LED 正极
3. LED 负极接 `GND`

简化表示：

```text
D12 -> 电阻 -> LED 正极
LED 负极 -> GND
```

建议：

- 电阻取 `220Ω` 到 `1kΩ`
- 如果灯太亮可适当增大电阻

---

## 7. 蜂鸣器 + 9013 + 二极管 接法

功能：

- 本机发送莫尔斯有效脉冲时蜂鸣器响

因为你要求使用 `9013 + 二极管`，这里按三极管驱动方式说明。

### 7.1 适用场景

这种接法尤其适合：

- 电流比 Arduino 引脚直驱更大的蜂鸣器
- 电磁式蜂鸣器
- 希望用三极管做隔离驱动的情况

### 7.2 连接关系

#### Arduino 控制侧

1. `D13` 通过 `1kΩ` 电阻接到 `9013` 基极
2. `9013` 发射极接 `GND`

#### 负载侧

1. 蜂鸣器负极接 `9013` 集电极
2. 蜂鸣器正极接 `5V`

#### 保护二极管

如果你使用的是**电磁式蜂鸣器或带线圈的负载**，建议并联一个反向二极管：

1. 二极管阴极接蜂鸣器正极一侧，也就是 `5V`
2. 二极管阳极接蜂鸣器负极一侧，也就是 `9013` 集电极这一侧

简化表示：

```text
D13 -> 1k 电阻 -> 9013 基极
9013 发射极 -> GND
9013 集电极 -> 蜂鸣器负极
蜂鸣器正极 -> 5V

二极管并联在蜂鸣器两端：
二极管阴极 -> 5V
二极管阳极 -> 集电极 / 蜂鸣器负极
```

### 7.3 为什么要加二极管

如果蜂鸣器内部是感性负载，关断时可能产生反向感应电压。  
二极管的作用是吸收这个反向尖峰，保护三极管和 Arduino。

### 7.4 如果是普通有源蜂鸣器

如果你手上的蜂鸣器本身是小电流有源蜂鸣器，有时可以直接驱动。  
但既然你已经明确要求 `9013 + 二极管`，那就建议统一按三极管驱动方案接，结构更稳。

## 8. 单块板子的完整本地连接图

```text
Arduino Uno
├── D2  -> 单线总线
├── D12 -> 电阻 -> 绿色 LED 正极
│                 绿色 LED 负极 -> GND
├── D13 -> 1k 电阻 -> 9013 基极
│                         9013 发射极 -> GND
│                         9013 集电极 -> 蜂鸣器负极
│                                         蜂鸣器正极 -> 5V
│                         二极管阳极 -> 集电极 / 蜂鸣器负极
│                         二极管阴极 -> 5V
└── GND -> 公共地
```

```text

---------                               ---------
D2   --------------------------------   D2
```

## 10. 接线检查清单

烧录前建议逐项确认：

- 两块板子的 `GND` 是否已经连接
- 两块板子的 `D2` 是否已经直连
- `D12` 是否接到 LED 正极方向
- LED 是否串联了限流电阻
- `D13` 是否通过电阻接到 `9013` 基极
- `9013` 发射极是否接地
- 蜂鸣器是否接在 `5V` 与 `9013` 集电极之间
- 二极管方向是否正确
- 若使用外部上拉，总线是否已正确上拉到 `5V`

---

## 11. 使用提醒

- 两块板子烧录同一份程序即可
- 打开两个串口监视器，波特率设为 `115200`
- 任意一端输入文本回车即可发送
- 发送时本机蜂鸣器响
- 接收时本机绿色 LED 亮

---

## 12. 常见错误

### 12.1 没有共地

表现：

- 串口看起来在发
- 但对面收不到

原因：

- 两块板子没有共同参考地

### 12.2 LED 方向接反

表现：

- 接收时串口有输出
- 但 LED 不亮

### 12.3 三极管脚位接错

表现：

- 发送时蜂鸣器不响
- 或一直响

注意：

- 9013 的引脚顺序请以你手上的器件型号资料为准
- 不同封装和供应商版本可能存在差异

### 12.4 二极管方向接反

表现：

- 蜂鸣器异常
- 三极管发热
- 电路不工作

### 12.5 没有上拉且线太长

表现：

- 总线不稳定
- 偶发误码

处理：

- 缩短连线
- 增加外部上拉电阻
